## 2. RQ-1 — Pilot topology + gateway architecture (node counts, gateway roles, Internet relay, mesh-primary test design)

**ANSWER: ADOPT-WITH-CONDITION.** The 50-100-leaf target is operationally proven for managed-flood meshes with traffic control (Meshtastic claims >100 nodes; firmware telemetry interval scale confirms the mechanism), the gateway+Internet-relay pattern has 2024 field precedent (Helene volunteer meshes), and DTN trials provide the evaluation vocabulary. Pilot topology = 50-100 leaves (Android relay-primary, iOS limited-relay) + 1-3 DESKTOP-001 (Tauri) gateways (Android-gateway fallback role) with gateway-scoped uplink/downlink to a private IRIS relay.
