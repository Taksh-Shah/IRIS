## RQ-2 Envelope fit — ADOPT (standard envelopes verbatim; REJECT bespoke struct)

- **340 B MO / 270 B MT is 96xx-module-scoped**: Hach ISBD-1 datasheet quoting
  Iridium specs (L3); Beam Communications (Iridium partner): "All transceivers
  with model number 96XX … 340 bytes sending / 270 receiving. 95XX handsets…
  much larger at 1960 bytes sending / 1890 receiving" (L1-partner). The doc's
  "340 B universal" framing is WRONG for handset class (9575 included).
- IRIS P0 envelope ≈237 B (full 64-B Ed25519 signature + full 32-B PeerIds)
  fits 96xx MO budget with ~103 B headroom; trivially fits handsets. No
  counter-evidence exists. Billing nuances: minimum billable message 10 B;
  mailbox checks billable ~$0.04–0.05/event when no MT queued (**RX costs
  money too**) (satellitephonestore L3; Beam L1-partner).
- **Design input D-2**: serialize the STANDARD CRYPTO-001 envelope verbatim
  into SBD payload. **DELETE `SbdIrisMessage`** and any signature truncation —
  a truncated 32-B Ed25519 signature is cryptographically void and violates
  CRYPTO-001. If >340-B carriage is ever needed on 96xx, fragment the ENVELOPE
  STREAM w/ reassembly + per-fragment MAC — never truncate crypto material.
  Drop LZ4 pre-compression for tiny payloads (overhead at this size; own
  benchmark before adopting — hypothesis pending).

## RQ-3 Cost-guard semantics — ADOPT-WITH-CONDITIONS

- Industry prior art (both vendors run on Iridium): **Garmin inReach** monthly
  quotas w/ $0.50/text overage; 2025 plan tiers Enabled/Essential ~50/
  Standard ~150/Premium unlimited; month-to-month, free suspension since
  Jun 2025 (garmin.com support + blog, L1). **Zoleo**: Basic $20/75 msgs,
  In Touch $35/300, Unlimited $50, $0.50 overage; **"SOS messages are included
  in all service plans and do not count toward your monthly message
  allotment"**; preset check-ins unlimited (zoleo.com plans, L1).
- Synthesized pattern: (1) emergency traffic exempt from ALL quotas/budgets;
  (2) routine traffic capped per billing period w/ soft overage, not hard
  block; (3) counters must persist locally across reboot/power loss and
  reconcile offline (billing-cycle resets).
- **Design input D-3**: SatelliteCostGuard redesign — P0 **never blocked**
  (bypasses hourly cap + daily budget entirely); P1/P2 subject to hourly
  count + daily monetary budget w/ hard-stop + queue-not-drop; counters
  persisted on every mutation; confirmation UX only for discretionary P1/P2;
  budget model includes RX-side billable mailbox checks. Gap: agency
  rationing guides (UN ETC style) supplementary-only, non-blocking.

## RQ-4 Integration patterns — ADOPT-WITH-CONDITIONS

- RFC 9171 BPv7 (+9713/9758): store-carry-forward overlay over constituent
  networks; convergence-layer adapters MUST rate-limit because long RTTs are
  incompatible with reactive end-to-end congestion control (rfc-editor.org,
  L1). BPSec (RFC 9172) = security layered ABOVE transport — same layering we
  assume.
- Latency reconciliation: official network transit ≈5 s short / ≈20 s max-
  length messages to gateway delivery (Beam/geoborders/IFP, L1-partner/L3);
  doc's "20–90 s" = practical end-to-end incl. polling cadence + relay
  processing. Both true contextually.
- **Design input D-4**: classify SBD transport as cost class **Expensive**,
  eligibility EmergencyOnly(P0–P2), ACK semantics asynchronous-opportunistic
  (custody-style acks carried in later sessions; retry intervals ≥ minutes,
  jittered; never assume RTT <90 s). CostGuard rate limiting lives in the
  transport adapter per RFC 9171 CLA requirement. Gap: optimal retry cadence
  under 10 msg/h needs simulation (SIMULATION_VALIDATED, G-5).

## RQ-5 Security — ADOPT-WITH-CONDITIONS (hostile pipe confirmed)

- arXiv:2603.12062 (Mar 12 2026; CCS-track): FIRST public systematic analysis
  of Iridium radio auth: SIM key extractable → full device cloning/
  impersonation; nearly all signaling/radio protocols unencrypted (cleartext
  credentials over >186M captured frames); SDR downlink SPOOFING demonstrated
  (devices accept fake Ring Alerts; no network-to-device authentication);
  replay of recorded auth bursts succeeds; jamming cheap (Ring Alerts arrive
  ≈−120 dBm; 0 dBm jammer disrupts regionally) (L2). RECORD attack (USENIX
  Sec 2024): passive geolocation of Iridium users to ~10 km (L2). Salkield
  2023: downlink overshadowing ~US$2000; LEO spot-beams easier to spoof than
  GEO (L2); IEEE Spectrum Jun 2025 coverage (L3).
- **Design input D-5**: envelope-layer verification above the transport is
  MANDATORY, not merely sufficient — the link provides ZERO usable
  authenticity/confidentiality. Conditions: (a) RX path verifies envelopes
  before ANY UI/alert surface; Ring Alerts are wake-up hints only, never
  content trust; (b) freshness windows tolerate multi-hour store-and-forward —
  per-sender monotonic sequence numbers, not timestamps alone (coordinate
  w/ CRYPTO-001 owner → G-7); (c) 1 mW jamming defeats the link — satellite is
  best-effort redundancy, never a sole lifeline; (d) metadata privacy:
  transmission reveals approximate location (acceptable for P0 SOS,
  documented). Gap: NTN Direct inherits SIM mutual auth — different profile,
  post-v1 evaluation.

## RQ-6 India regulatory 2025–2026 — ADOPT-WITH-CONDITIONS (doc summary REPLACED)

- Starlink timeline (doc's "DoT approved 2024" WRONG): DoT LoI May 7 2025;
  GMPCS licence granted ~Jun 5–6 2025; IN-SPACe authorization Jul 9 2025
  (Gen1, valid→Jul 7 2030); spectrum assignment Sep 2025; testing Oct 2025
  (9 gateway earth stations); commercial launch still pending mid-2026,
  targeted late 2026 (Reuters/India Today, L2/L3).
- **Telecommunications Act 2023** (No. 44 of 2023, effective Dec 24 2023)
  replaced the Telegraph Act framework: unauthorized possession/use of
  satellite phones/two-way messengers is a CRIMINAL offense (up to 3 years
  imprisonment); Customs Circular 37/2010 import controls remain (declare +
  DoT permission). Devices in the prohibited-without-permission class include
  Garmin inReach, SPOT, and **Iridium GO!** (statute L1 via L3 summaries + L4
  guides).
- **Doc claim "Bharti Airtel is Iridium's India partner" FAILS VERIFICATION**
  (L5 → treat as FALSE): exhaustive search finds only Airtel–Starlink
  distribution/Direct-to-Cell relationships and Bharti–OneWeb ownership.
  TRAI satcom recommendations May 9 2025: administrative allocation, 4% AGR,
  ₹500/subscriber/yr urban, nil rural (L3).
- **Design input D-6**: field units with satellite TX capability require
  operation under an authorized GMPCS/MSS provider's terms + terminal
  registration; unlicensed satellite TX in India is now a criminal matter →
  **HIGH-RISK LEGAL GATE: no field activation of satellite TX in India
  without legal sign-off**. Identify the authorized Iridium airtime channel
  post-Telecom Act 2023 = LEGAL_REVIEW gap (not web-resolvable). Starlink =
  out-of-core + commercially unavailable in India until late 2026 → 2027+
  option.
