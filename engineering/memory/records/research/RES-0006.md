## Key Design Decisions

### Integration Pattern
The Message Engine (Layer 5) sits between:
- Below: Storage Layer (SQLite) + Transport Layer (BLE/WiFi/LoRa/etc.)
- Above: Routing Engine (Layer 3) + Security Layer (Layer 6)

Its responsibilities:
1. Message lifecycle management (CREATED → PENDING → IN_TRANSIT → DELIVERED/EXPIRED)
2. Priority queue management (weighted fair queue with P0 preemption)
3. TTL enforcement (absolute expiry with clock skew budget)
4. Deduplication (Bloom filter + LRU cache)
5. ACK tracking and retry logic
6. Fragment reassembly
7. Storage interface (persist, load, evict)
8. Transport interface (send via TransportManager)

## Gaps Identified

1. **Retry strategy** — exponential backoff parameters not defined
2. **ACK timeout** — specific timeout values per priority not defined
3. **Queue starvation prevention** — 60s timer mentioned but not formalized
4. **Fragment reassembly timeout** — 30s mentioned but not configurable
