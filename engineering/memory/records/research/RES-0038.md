# RES-0038 — Shared-writer receipt timestamp compile failure

**Date:** 2026-09-08  
**Node:** INTERNET-ANDROID-001  
**Trigger:** First compile after relay liveness/ACK hardening failed with E0425.

The receipt used `now` after the writer-release logic was split between the
relay-ACK and plain branches. Each `now` binding lived only inside its branch,
so neither was visible at receipt construction. The Rust Reference defines a
block as an anonymous scope and a `let` binding as extending only to the end of
the block where it is declared:
https://doc.rust-lang.org/reference/names/scopes.html and
https://doc.rust-lang.org/reference/expressions/block-expr.html.

**Decision:** construct a distinct `sent_at` after the branches, where it is in
scope for the receipt. Also remove the compile-reported unnecessary `mut` and
the verifier-identified unused test import before retrying.

**Maturity:** L4 language reference plus L1 compiler evidence.
