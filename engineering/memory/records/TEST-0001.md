## 3. Tests Added

### internet.rs (`crates/iris-core/src/transport/internet.rs`)
| Test | Proves |
|------|--------|
| `encode_frame_rejects_oversized_payload` (`#[should_panic]`) | Encode refuses payloads `> MAX_FRAME_BYTES` — oversized frames never reach the wire. |
| `frame_payload_len_rejects_truncated_header` | Headers shorter than the 4-byte length prefix → `None`; absurd 4-byte length claims also rejected. |
| `connection_pool_reuses_socket_for_back_to_back_sends` | One relay socket accepts 2 frames in order — the pool hands the *same* pooled `OwnedWriteHalf` to the second `send()` instead of dialing again. |
| `backoff_capped_and_monotonic_across_attempts` | `backoff_ms` stays in `[500, 37500]`, is monotonic non-decreasing across attempts `1..=10` for every seed, and achieves cap-at-attempt: attempts `5..=31` yield identical jittered values per seed. |

### manager.rs (`crates/iris-core/src/transport/manager.rs`)
| Test | Proves |
|------|--------|
| `multipath_excludes_unavailable_transports` | P0 multipath returns ALL viable transports (Connected + Degraded) and excludes Unavailable/Connecting (negative-score) candidates; every returned score `> 0`. |
| `ranking_prefers_connected_over_degraded` | With identical caps/cost, the only differentiator is state: Connected (baseline 40) outranks Degraded (baseline 5). |
| `registers_ten_transports_without_panic` | A fully-equipped node can register 10 transports without panic; all 10 resolvable via `get()`/`list()`. |

### ble.rs (`crates/iris-core/src/transport/ble.rs`)
| Test | Proves |
|------|--------|
| `shutdown_sets_unavailable_and_disconnects` | `shutdown()` transitions state to `Unavailable` AND drives `disconnect_gatt` on the adapter (via new `RecordingBleAdapter`). |
| `scan_and_advertising_handles_round_trip` | `discover_peers` → `start_scan(ScanFilter)` stores the handle; `stop_discovery` passes the *exact* `ScanHandle(1)` back; same round-trip for `AdvHandle(1)` via `start_advertising`/`stop_advertising`. |

### simulated.rs (`crates/iris-core/src/transport/simulated.rs`)
| Test | Proves |
|------|--------|
| `same_seed_produces_identical_loss_outcomes` | Two transports seeded identically (loss 0.5, 20 sends) deliver the *same* message set — the DROP SET is identical, not just "roughly similar". Asserts loss is actually exercised (delivered count strictly between 0 and 20). |

### message.rs (`crates/iris-core/src/message.rs`)
| Test | Proves |
|------|--------|
| `priority_round_trips_p0_to_p7` | `from_u8(as_u8(p)) == p` for every P0..P7. |
| `priority_rejects_out_of_range` | `from_u8` returns `None` for 8, 200, 255; boundary P7 = 7 accepted. |
| `emergency_true_only_for_p0_p1` | `is_emergency()` true only for P0/P1, false for P2..P7. |
| `priority_order_puts_emergency_first` | Ordering invariant: P0 < P1 < ... < P7 (lower discriminant = higher priority). |
