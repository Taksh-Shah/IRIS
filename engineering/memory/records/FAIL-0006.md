# FAIL-0006 — Mobly Tier-2 retried by creating new message IDs

**Date:** 2026-09-06  
**Node:** WIFIDIRECT-001 hardware verification  
**Attempt:** Mobly `test_wifi_direct_cold_start_election`, cycle 1/10

## Failure

The harness reported `P1->P2 delivered=False` after 68.4 seconds even though
both devices reported `wifi-direct-0: Connected`.

## Evidence

- Run: `docs/bug-hunting/hardware_verification/evidence/run-20260906-1001/`
- Failure bundle: `FAIL-test_wifi_direct_cold_start_election/`
- P1: `p2pSend ... no live socket (link=false, accepts=true)` and
  `transport: busy`
- P2: `security.replay_detected` for message ID
  `01a074fd07587f81...`
- Later messages in the same run were delivered, proving the radio/group path
  was not uniformly unavailable.

## Lesson

The test must not create a new message for each delivery poll. A single
message ID must be observed until delivery or the cycle deadline.

## Remediation

Update the Mobly test helper only, preserve the production implementation, and
rerun the same ten-cycle gate. Do not mark Mobly Tier-2 green until all ten
cycles pass with the required evidence.
