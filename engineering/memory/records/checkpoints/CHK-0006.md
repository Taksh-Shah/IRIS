## Key Architectural Achievement

The system has been upgraded from:

```
STATE → NODE → TASK → CHECKPOINT → STOP
```

to:

```
STATE → GRAPH SELECTOR → ACTIVE NODE → NODE LOOP → ACCEPT → GRAPH UPDATE → NEXT NODE → CONTINUE ↺
```

The supervisor reads `execution-state.yaml` after every action, determines the next eligible work item, and continues. It stops ONLY for: mission completion, human gates, unrecoverable blockers, or fatal failures.
