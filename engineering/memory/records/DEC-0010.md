## Decision

The operator **ratifies tracking RED-0001 (CRITICAL) to IDENT-001** and directs
CRYPTO-001 to proceed to VERIFY → ACCEPT → COMPLETE with RED-0001 recorded as a
known_limitation plus an explicit security control.

- **RED-0001**: the only production binary (`iris-desktop`) still wires the
  inert `DevCryptoProvider` (`engine_handle.rs:145`: sign `[0xFF;64]`, verify
  `Ok(true)`, encrypt passthrough); no key directory configured; node identity
  regenerates per process (`default_node_id`); no at-rest sealer installed.
  The CRYPTO-001 **core** (IrisCryptoProvider + engine send/deliver wiring +
  at-rest RowSealer/StorageKeySealer) is complete and test-backed
  (workspace 290 green). Desktop wiring — real key directory, persisted
  identity, sealer application on PgStorage — is **absorbed by IDENT-001**
  (P0, deps CRYPTO-001).

## Rationale

- RISK_POLICY: CRITICAL findings halt for operator report. The finding was
  reported (CRYPTO-001_SECURITY_REVIEW.md, RED-0001) and is now ratified.
- The vulnerable path is the **desktop developer harness**, not the engine
  runtime: every provider/seal path exercised in tests uses the real
  cryptographic stack. No production mesh node exists yet (hardware transports
  are software-only implementations awaiting devices, BLK-0005).
- Building the durable identity/key-provisioning/sealer plumbing twice (once in
  CRYPTO-001, again in IDENT-001) would duplicate the exact component IDENT-001
  owns. Tracking is the correct scope boundary.

## Security control (ratified)

`CRYPTO-001` is ACCEPTED **with** the following enforced control:

> **No production deployment may run with `DevCryptoProvider` or without a
> provisioned identity + key directory + configured sealer.** IDENT-001 MUST
> wire IrisCryptoProvider (real key directory, persisted per-device identity,
> `PgStorage::with_sealer`) into `iris-desktop` before end-user/field use.
> Until that lands, desktop v1 remains documented as a development harness with
> per-process identity and no at-rest protection across launches.
